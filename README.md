# NestedGainPhaseExample.jl

Numerical example for the paper [[1]](#1).

## How to Run

Inside the repo, start Julia and enter:
```julia-repl
julia> using Pkg; Pkg.activate("."); Pkg.instantiate()
julia> include("main.jl")
```

After some calculations, the figure from the paper should appear.

---
<a id="1">[1]</a> A. Ponomarev. *Compositional small-gain and small-phase stability analysis*. 2026. [arXiv:2606.14745](https://arxiv.org/abs/2606.14745).
